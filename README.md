APL Бие даалт
Сэдэв: 27. Зогсоолын төлбөр
Өөрийн тогтоосон дүрмүүд (Business Rules)
Энэхүү бие даалтын ажлын хүрээнд зогсоолын төлбөр тооцох дараах дүрмийг өөрөө тогтоож хэрэгжүүлсэн болно.
Машин зогсоолд орж ирснээс хойш эхний 30 минут бүрэн үнэгүй байна.
30 минутаас хэтэрсэн тохиолдолд илүү гарсан цаг тутамд (эсвэл 30 минут тутамд) 1,000₮-ийн төлбөр бодогдоно.
Тухайн өдөр үйлчилсэнэлемент хэрэгжсэн байдал
1. **Оролт/Гаралт:** `scanf`/`fgets` болон `readInts` функцээр дор хаяж 4 оролт (`n`, `hIn`, `mIn`, `hOut`, `mOut`) авч, үр дүнг `printf`-ээр хүснэгт хэлбэрээр цэгцтэй хэвлэсэн.
2. **Үйлдэл ба илэрхийлэл:** Арифметик (`+`, `-`, `*`, `/`) болон логик (`&&`, `||`) үйлдлүүд хоёулаа орсон.
3. **Нөхцөл:** `if-else` шатлал болон олон нөхцөл шалгах логик хэрэгжсэн.
4. **Давталт ба хүснэгт:** `for` болон `while` давталт ашиглан 5-аас дээш мөр бүхий хүснэгт хэвлэсэн (`%-10d`, `%02d:%02d` гэх мэтээр багануудыг тэгшилсэн).
5. **Дэд алгоритм:** Flowgorithm болон C программ дээр функц ашиглах шаардлагыг хангасан.
6. **Эрэмбэлэлт / Хайлт:** Давталт дундуур хамгийн удаан зогссон машиныг олж бүртгэх хайлтын логик (`parkedMinutes > maxMinutes`) орсон.
7. **Оролтын шалгалт:** Буруу утга (сөрөг тоо, цаг минутын хязгаараас гадуур утга) орж ирэхэд `while` болон `readInts` функцээр дахин шаардаж алдааг залруулдаг.

4. Программ ажиллуулах заавар (GCC)
Кодыг компиляци хийж ажиллуулахын тулд терминал дээр дараах командуудыг бичнэ: машины хамгийн бага тоо 5 байх ба цаг нь 0–23, минут нь 0–59 хооронд байх ёстой.
